Gargantua from *Interstellar*, rendered with GLM5.3 + Trae. One shot + two rounds of optimization — the first version and the final one differ only in details.

My API credits were about to expire with nowhere to use them 😂. I rewatched Interstellar recently and got curious whether Gargantua could be rendered in a web page 😮

Clone the repo and open index.html to see it in action

**Note: Your browser must support WebGL2. Use the latest Chrome / Edge / Firefox**

**LOW / MED / HIGH quality presets are in the top-right corner. HIGH needs roughly an RTX 3060-class discrete GPU to hold 60 FPS; on integrated graphics, MED is recommended**
